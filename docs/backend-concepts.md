# Backend 교과서 — RemoteUpdate 로 배우는 Spring Boot

RemoteUpdate 를 만들면서 실제로 쓴 개념을 **기초부터 차례대로** 정리한 공부용 교과서입니다.
모든 설명은 "왜 이게 필요하지?" 에서 시작해 "그래서 우리 코드는 이렇게 했다" 로 끝납니다. 예시 코드는 전부 이 저장소에 실제로 있는 코드입니다.

## 이 책을 읽는 법

- **처음부터 순서대로** 읽도록 썼습니다. 앞 장에서 나온 개념을 뒤 장에서 "○장에서 본 것처럼" 하고 다시 씁니다.
- 각 장은 **이야기(왜 필요한가) → 개념 → 우리 코드 → 정리 → 확인 문제** 순서입니다. 확인 문제의 답은 [부록](concepts/09-appendix.md#확인-문제-정답)에 있습니다.
- `> 코드:` 로 표시한 파일을 IDE 에서 함께 열어 보세요. 코드 주석에도 같은 설명이 달려 있습니다.
- 3계층(Controller · Service · Repository)과 REST 를 이미 안다면 1부와 2부는 빠르게 훑어도 됩니다. 다만 "알고 있다고 생각했는데 이유는 몰랐던" 부분이 꽤 있을 거예요.
- 보안을 더 깊게 보려면 5부를 읽은 뒤 [security-guide.md](security-guide.md) 로 넘어가세요.

## 전체 지도: 요청 하나의 여행

이 책 전체는 결국 아래 그림 하나를 이해하는 과정입니다. 직원이 브라우저에서 "업데이트 1.1.0 다운로드" 를 누르면:

```
브라우저 ──HTTP 요청──▶ 톰캣(내장 웹 서버) ── 요청마다 스레드 하나 배정 (2부 10장)
                          │
                          ▼
                 ┌─ 필터 체인 (스프링 시큐리티) ─────────────── 5부
                 │   세션에서 로그인 정보 복원 → CSRF 검사 → 세션 갱신
                 │   → 권한 검사 → IP 제한 → 비밀번호 변경 필요 검사
                 └────────────┬──────────────────────────────
                              ▼
                 DispatcherServlet ── 어느 컨트롤러 메서드? (3부 15장)
                              ▼
                 Controller  ── 주소·파라미터 해석, 입력 검증 (3부 16~17장)
                              ▼
                 Service     ── 업무 규칙 + 트랜잭션 (프록시가 감쌈) (3부 13장, 4부 20장)
                              ▼
                 Repository  ── JPA 가 SQL 을 만들어 실행 (4부)
                              ▼
                 MariaDB     ── 커넥션 풀로 연결 (4부 21장)
                              │
       ◀── 응답: JSON 은 Jackson 이 변환 (1부 3장) / 파일은 스트리밍 (6부)
```
